# Payments API

REST API for managing customers and payment operations, developed with Java and Spring Boot.

## About the Project

Payments API is a backend project designed to manage customer registrations and payment operations, following software development best practices, REST principles, and database integrity rules.

The project is being developed as a practical study of backend engineering, focusing on Java, Spring Boot, database management, automated testing, and containerization.

## Technologies

- Java 21
- Spring Boot 4
- Spring Data JPA / Hibernate
- PostgreSQL
- Flyway
- Maven
- Bean Validation
- JUnit and Mockito
- Testcontainers
- Docker
- Nginx

## Planned Features

- Customer registration and management.
- Support for individual customers (CPF) and business customers (CNPJ).
- Payment creation and management.
- Payment status management.
- Payment methods: PIX, Credit Card, and Debit Card.
- Data validation and business rules.
- Global exception handling.
- Database versioning with Flyway.
- Unit and integration testing.

## Architecture

The project follows a domain-oriented package structure, separating customer and payment responsibilities.

## Project Status

<text>Currently under development.</text>

The initial database schema is implemented using PostgreSQL and Flyway. The next development stage focuses on JPA entities and persistence.
